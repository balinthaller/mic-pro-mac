## 短帖

给 Insta360 Mic Pro 写了个原生 Mac 小工具。

菜单栏/侧边停靠看电量、充电和内录；改墨水屏壁纸、导出录音，还能让 Agent 通过本机 CLI 调用。

从蓝牙协议研究一路做到实机插拔验证。Swift 实现，MIT 开源预览版，目前只在一台 Mic Pro 上测过。

## 开发过程串帖

1/ 给 Insta360 Mic Pro 做了一个原生 macOS 小工具：Mic Pro Mac。

原本只是想在电脑上看电量，后来加上了侧边停靠、录音导出、墨水屏壁纸和本机 Agent 接口。

这是非官方的个人开源项目。

2/ 最有意思的是“充电状态”。

macOS 只能给出比较粗的电量缓存，我从固件与协议研究里找到了电池查询，再在自己的设备上做插线→拔线→重插对照。

供电字段确实是 1→0→1，现在能显示在电量旁边。

3/ 壁纸也做成了完整流程：

导入自己的图片→预览/裁切/六色量化→备份当前图→上传→完整读回校验。

墨水屏刷新慢，适合低频状态图或静态设计。录音也能通过蓝牙或 USB 导出，原件保留。

4/ 还留了一个本机 CLI 给 Agent：

micpro status
micpro vibrate
micpro recordings-list
micpro wallpaper-backup

接口通过本机文件收发请求，没有网络监听。这个小麦克风也可以成为 Agent 的桌面反馈入口。

5/ 源码按 MIT 开源，公开包做了单独整理：

显式配置自己的设备；录音、日志和备份留在本机；Codex 额度模块默认关闭；实验性诊断也默认关闭。

目前核心功能只在一台 Mic Pro TX、固件 2.0.2.4 上测过。欢迎其他设备/固件的开发者反馈。

## 配图与视频脚本

建议配实际界面截图或20–30秒短视频，按这个顺序：

- 0–5秒：菜单栏和侧边停靠，展开电量旁的充电状态。
- 5–12秒：⌃⌥M打开控制面板，展示内录状态与输入/输出选择。
- 12–20秒：展示一张你愿意公开的墨水屏图片与壁纸编辑预览。
- 20–30秒：展示录音列表与 CLI 的 status 输出。

拍摄前检查：隐藏设备后缀、蓝牙地址、私人壁纸、录音文件名和 Codex 账户额度。不要把示意图包装成实机截图。

## 适合强调的点

个人需求驱动、原生 Swift/AppKit、协议研究到实机验证、硬件成为 Agent 反馈入口、对备份/读回和失败状态认真处理。

## 暂不宣称

官方支持、适配全部 Mic Pro/固件、精确续航、准确识别充满/充电暂停、独立震动马达指令、任意 LED 颜色、手机无重启接管已稳定解决。
